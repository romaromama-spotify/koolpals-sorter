How to use it on iPhone

  1. Publish this single index.html file at an HTTPS address using a static web host (GitHub Pages works).
  2. Open your published address in Safari, copy the Redirect URI, and add it to a Spotify developer app.
  3. Paste the app's Client ID here, tap Connect with Spotify, then approve access.
  4. Preview the sorted guestings. Download a backup if desired. Tap Sort my Spotify playlist to apply.
  5. In the Spotify iPhone app, choose Custom order for this playlist to see the new permanent order. Optionally use Safari's Share menu → Add to Home Screen.
